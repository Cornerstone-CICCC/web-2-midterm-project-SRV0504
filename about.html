About

FlickTime is your ultimate gateway to the world of cinema and television. Built using the TMDB API, this platform curates trending and popular movies in real time — delivering an experience that’s both visually immersive and dynamically updated.

This project was designed not only to showcase development skills in JavaScript, HTML, and API integration — but also to demonstrate how design and functionality can come together in one seamless cinematic experience.
